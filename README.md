# Nexgensoft-UI

Nexgensoft kurumsal site — React (Vite) + i18n.

## Yerel kurulum

1. `copy .env.example .env` (Windows) — API adresini düzenleyin.
2. `npm install`
3. `npm run dev`

CoreService ile birlikte çalıştırmak için `.env` içinde `VITE_API_BASE_URL` ve gerekirse `VITE_USE_REMOTE_CONTENT` ayarlarına bakın.
